# Packages

Intended monorepo structure for CKScope (npm workspaces). These folders are placeholders — they describe the planned shape of the project, not released code.

| Package | Role |
|---------|------|
| `backend/` | REST API + sync layer (Node.js / TypeScript) |
| `frontend/` | React web UI |
| `shared/` | Shared TypeScript types used by both backend and frontend |
